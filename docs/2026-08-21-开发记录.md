# 2026-08-21 开发记录

> 日期：2026-08-21
> 记录范围：学生端改版 —— 从「直接看题库题目」改为「看试卷 → 进试卷答题 → 按考试时间窗作答 → 到点自动交卷」

## 一、需求背景

学生端原先直接展示题库题目列表，学生能直接拿到题库里的题。本次按要求改版：

- 学生看到的是**试卷（考试）**，不是题库题目
- 点进试卷后才能看到试卷里的题目
- 只有教师端发布的考试时间窗内（startTime~endTime）才能作答
- 到结束时间自动交卷

## 二、后端改动（Spring Boot）

### 1. 提交记录挂考试 ID

- `Submission` / `SubmissionDetail` 实体新增 `examId` 字段（含 `@Column` + 索引 `idx_submissions_exam_id`）
- `schema.sql` 同步新增 `exam_id` 列；**现有 MySQL 库已手动 `ALTER TABLE` 迁移**（`ADD COLUMN exam_id ... ADD KEY ...`）
- `SubmissionRepository` 新增 `findFirstByStudentIdAndExamId`、`findByStudentIdAndExamId`

### 2. 新增考试相关 DTO

- `StudentExamSummary`（列表项：标题/班级/时间窗/状态/题数/总分/是否已交卷）
- `StudentExamDetail`（详情：上面字段 + 展开后的题目列表）
- `StudentExamQuestion`（试卷内一题：标题/难度/分值/描述/方法名/语言/测试用例 + 已交卷时的源码/状态/得分）
- `ExamSubmitRequest`（整卷交卷请求：`answers[{questionId, sourceCode}]`）
- `ExamSubmitResult`（交卷结果：examId/交卷时间/已作答数/总数）

### 3. StudentService 新增三个方法

- `listExams()`：只查 `status=PUBLISHED` 的考试，逐场算时间窗状态 + 是否已交卷
- `getExam(examId)`：校验已发布；展开每道题完整内容；已交卷时带回源码/状态/得分
- `submitExam(examId, request)`：三道校验（已发布、时间窗内留 60 秒容错、同一考试只交一次）；逐题落库，**未作答记 `UNANSWERED` 0 分**、已作答记 `PENDING` 并触发评测

### 4. StudentController 新增接口

- `GET /api/student/exams`、`GET /api/student/exams/{id}`、`POST /api/student/exams/{id}/submit`
- 旧的 `/questions`、`/submissions` 接口保留未动

### 5. 评测接口骨架（本次「先做个接口」）

- 新增 `JudgeEngine` 接口抽象：`void judge(Long submissionId)`，为后续接入真实评测引擎（Judge0 / 本地沙箱）留好契约
- 新增 `StubJudgeEngine` 占位实现：只打日志、不改判卷状态
- `JudgeService` 重构为门面：读评测配置 + 记触发日志，实际评测委托给 `JudgeEngine`（`trigger()` → `engine.judge()`）
- 新增管理端 HTTP 接口 `POST /api/admin/judge/{submissionId}`（`JudgeController`）+ 响应 DTO `JudgeTriggerResult`，带 `@AuditOperation` 审计
- 更新 `JudgeServiceTest` 适配新构造并校验委托调用
- 验证：管理员触发返回 `{submissionId, accepted=true}`；学生 token 403；无 token 401；日志出现「评测引擎未接入（占位）」

## 三、前端改动（Vue 3 + Vite）

- `api/student.js`：新增 `listExams` / `getExam` / `submitExam`
- `utils/format.js`：新增 `UNANSWERED: 未作答` 状态文案
- `StudentHome.vue`：改为「我的考试」试卷列表（状态徽章：未开始/进行中/已结束 + 已交卷）
- **新建 `ExamSolve.vue`**（进试卷答题页）：
  - 每题一个 Monaco 编辑器（Java），开考前只读、进行中可作答
  - 倒计时（时分秒），**到 0 自动交卷**
  - 答题内容实时存 localStorage 草稿（`codejudge_draft_{examId}_{questionId}`），交卷后清草稿
  - 交卷后重新拉详情 → 切换只读回看（显示源码/状态/得分）
- `router/index.js`：新增 `exams/:id` 路由（保留原 `questions/:id`）
- `StudentLayout.vue`：侧边栏「考试首页」→「我的考试」

## 四、验证结果

- 后端 `mvn compile` 通过；重启后 8080 正常
- 前端 `npm run build` 通过（仅 Monaco 包体偏大的提示，非错误）
- curl 端到端联调：
  - `GET /student/exams` → 返回 1 场 `ONGOING` 考试
  - `GET /student/exams/{id}` → 展开 1 道题（标题/难度/方法名/语言）
  - `POST .../submit` → 返回 `answeredCount=1/totalCount=1`
  - 重复交卷 → 400「该考试已交卷，不能重复交卷」
  - 交卷后回看 → `submitted=true`、带回源码、`judgeStatus=PENDING`
