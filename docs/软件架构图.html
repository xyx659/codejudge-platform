三条关键数据流

同步业务链路

  1. 前端经网关鉴权与限流
  2. 业务服务处理用户、题库、考试请求
  3. 试卷快照预热到 Redis
  4. 学生开考直接命中缓存
  5. 未命中回源 PostgreSQL

异步判卷链路

  1. 提交进入 Redis 判卷队列
  2. Worker 消费并调用 Judge0
  3. AI 异步完成白盒分析与评语
  4. 结果写 PostgreSQL
  5. WebSocket 推送进度与成绩

反作弊数据流

  1. 浏览器行为埋点上报
  2. 事件写入 Redis Stream
  3. 行为分析与代码查重
  4. 可疑行为实时预警教师端
  5. 结论落库留作审计依据
