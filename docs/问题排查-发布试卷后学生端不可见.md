# 问题排查：发布试卷后学生端拿不到试卷

> 记录日期：2026-08-18
> 现象：教师端「发布试卷」后，学生端看不到、也无法进入该试卷。

## 一、问题描述

教师端组卷并点击「发布试卷」后，学生端考试首页依然看不到这场考试，无法进入答题。

## 二、根因

「发布试卷」和「学生端列表」操作的是**两套互不相通的数据模型**：

- 教师端「发布试卷」发布的是 `Exam`（组卷结果），存入 MongoDB 的 `exams` 集合；
- 学生端从头到尾只读 `questions` 集合里的**单个题目**，没有任何读取 `exams`（考试/试卷）的代码。

因此老师发布的试卷，对学生端的查询来说完全不可见——两者连交集都没有。

## 三、涉及代码位置

### 教师端（发布的是「试卷」）

| 文件 | 关键点 |
|------|--------|
| `backend/.../entity/Exam.java` | `@Document(collection = "exams")`，`status` 状态机：`DRAFT → PUBLISHED → CLOSED` |
| `backend/.../service/ExamService.java` | `publish(id)` 仅将 `Exam.status` 置为 `PUBLISHED` 并写回 `exams` |
| `backend/.../controller/teacher/ExamController.java` | `PUT /api/teacher/exams/{id}/publish` 发布考试 |

### 学生端（读的是「题目」）

| 文件 | 关键点 |
|------|--------|
| `backend/.../service/StudentService.java` | `listQuestions()` 查 `questions` 集合中 `published=true` 的 `Question`，与 `exams` 无关 |
| `backend/.../controller/student/StudentController.java` | 学生端端点只有 `/questions`、`/submissions`，**没有 `/exams`** |
| `frontend/src/api/student.js` | 只封装题目/提交相关函数，无考试相关函数 |
| `frontend/src/views/student/StudentHome.vue` | 页面虽叫「考试首页」，实际调用的是 `listQuestions`（题目列表） |

## 四、补充说明

教师端存在两个易混淆的「发布」动作：

1. **发布题目**：修改 `TeacherQuestion.published`。由于 `Question` 与 `TeacherQuestion` 映射到同一个 `questions` 集合，所以发布题目后学生端能看到（`published=true` 过滤命中）。
2. **发布试卷**：修改 `Exam.status = PUBLISHED`，写入 `exams` 集合。学生端没有对应读取逻辑，所以看不到。

本问题只涉及第 2 种情况。

## 五、修复方案

需要新增学生端「考试/试卷」能力，打通 `exams` 集合的读取链路：

### 后端

1. `StudentService` 新增：
   - `listExams(page, size)`：查询 `exams` 中 `status=PUBLISHED`、且当前时间落在 `startTime ~ endTime` 窗口内的考试，返回 `ExamSummary` 分页；
   - `getExam(id)`：返回试卷详情（含组卷题目快照 `questions`）。
2. `StudentController` 新增：
   - `GET /api/student/exams`（考试列表）；
   - `GET /api/student/exams/{id}`（试卷详情，含组卷题目）。

### 前端

3. `frontend/src/api/student.js` 新增 `listExams()`、`getExam(id)`；
4. `StudentHome.vue` 改为展示「可参加的考试」列表，点击进入加载试卷题目；再根据试卷题目进入答题/提交流程。

### 待确认

- 时间窗口：`startTime` 未到 / `endTime` 已过 / `status=CLOSED` 的考试，学生端应如何表现（隐藏？置灰只读？）。
- 答题口径：进入试卷后，是「每道题一次提交」还是「整卷一次提交」，会影响前端交互与后端 `Submission` 数据结构（当前 `Submission` 仅关联单个 `questionId`）。
- 提交接口是否需要新增 `examId` 字段，以把成绩归入对应考试。
