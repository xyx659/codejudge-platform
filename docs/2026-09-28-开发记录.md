## 一、今天已完成

### 1. 修复本地「测试」按钮无响应（核心 bug）

**问题**：学生端点「测试」按钮后没有任何反应（结果区、错误提示都不出现）。

**根因**：`question.value` 里的 `testCases` 是 Vue 的响应式 Proxy 对象，传给 Web Worker 的 `worker.postMessage(...)` 时走结构化克隆，Proxy 无法被克隆，浏览器抛 `DataCloneError: Proxy object could not be cloned`。该异常使 `runLocalTests` 的 Promise 直接 reject，而调用方 `runTest` 里只有 `finally` 没有 `catch`，异常变成未捕获 rejection，按钮闪一下就恢复，表现为「没反应」。

**定位方式**：用 Firefox 无头浏览器 + geckodriver 驱动真实页面，注入 `unhandledrejection` 监听捕获到报错。

**修复**（`jsRunner.js` 的 `runLocalTests`）：
- `postMessage` 前用 `JSON.parse(JSON.stringify(...))` 深拷贝成纯对象，去掉 Vue Proxy
- 整体包一层 `try/catch`，任何启动错误都以 `compileError` 返回，而不是静默 reject

### 2. 测试结果只显示未通过用例

**需求**：只显示未通过的用例，通过的不显示；全部通过时显示「全部通过」。

**实现**（`QuestionSolve.vue`、`ExamSolve.vue`）：
- 新增 `failedResults` 计算属性：`(testResults || []).filter(r => !r.passed)`
- 全部通过时展示绿色「✓ 全部通过（N 个用例）」，否则只列出失败项（实际/期望输出）

### 3. 我的成绩页增加搜索

**实现**（`StudentScores.vue`）：新增 `keyword` 输入框 + `filteredExams` 计算属性，按考试名称或题目名称过滤，输入时重置页码。

### 4. 题目详情补方法签名

**问题**：题目缺少 `methodSignature`，答题页生成的方法模板退化为 `public Object sum()`（无参数），即使有测试用例也跑不对。

**修复**：`QuestionDetail` DTO 增加 `methodSignature` 字段并透出；`QuestionSolve.vue` 的 `defaultTemplate` 改用 `q.methodSignature` 生成准确签名（与 `ExamSolve.vue` 一致）。同时给现有题目数据补上 `methodSignature = "int sum(int a, int b)"`。

## 三、技术要点

1. **Vue Proxy 与 postMessage 不兼容**：响应式对象不能直接传给 Worker，需要深拷贝成纯对象。这是「按钮无反应」这类隐性 bug 的常见来源。
2. **结构化克隆限制**：`postMessage` 只能克隆可序列化数据（无函数、无 Proxy、无 DOM 节点）。
3. **调试方法**：无头浏览器（geckodriver + Firefox）+ `unhandledrejection` 监听，能拿到普通 curl / node 模拟拿不到的浏览器运行时错误。
