# 数智化编程考核与智能分析系统 —— 软件设计文档

> 提取自《创业训练项目申报书》

---

## 一、项目概述

本项目面向高等院校编程类课程考核改革需求，研发一款适配国内高校教学场景的**AI增强型在线编程考试平台**，平台集成在线编程环境、自动判卷、多维度反作弊、学情数据分析、课程题库管理等核心功能，可完整支撑平时作业、随堂测验、实验考核、期末机考等全流程教学评价工作。

项目紧扣国家教育数字化战略与"人工智能+教育"发展要求，依托AI大模型前沿技术，面向高等教育软件工程等相关专业，打造集**智能评测、过程诊断、公平防弊、个性化导学**于一体的智能化教学支撑平台。

---

## 二、软件架构

### 2.1 总体架构

平台采用**分层式 B/S 软件架构**，整体分为四大层级：

| 层级 | 说明 |
|------|------|
| **前端展示层** | 面向学生、教师、管理员提供三类专属交互界面，覆盖全流程考试教学需求 |
| **API 网关层** | 以 Nginx 或后续独立网关作为统一入口，实现路由转发、JWT 登录鉴权、RBAC、限流与操作审计，保障系统安全与前后端解耦 |
| **数据层** | 采用 MySQL + MongoDB 混合存储：MySQL 存储用户、提交记录元数据等结构化数据，MongoDB 存储题目、提交答案明细与 AI 评审报告，依托大模型承载 AI 双维度判卷、代码查重反作弊等核心智能能力 |
| **基础设施层** | 以 Docker 容器化沙箱保障代码运行安全，搭配文件存储、定时任务实现自动化运维 |

### 2.2 架构特点

- **分层解耦**：各层职责清晰，易开发维护
- **适配小团队**：适配 3 人小团队研发运维
- **双部署支持**：支持高校本地化与云端双部署
- **高稳定性**：可稳定支撑在线编程考试全流程业务
- **模块化松耦合**：具备良好的功能扩展与二次开发能力

## 三、核心技术架构

### 3.1 技术栈

| 类别 | 技术选型 |
|------|----------|
| **前端** | Vue 3 |
| **后端** | Java 17 + Spring Boot 3 + Redis |
| **评测内核** | Judge0 CE（开源） |
| **AI/LLM** | DeepSeek API 或本地部署千问大模型 |
| **数据库** | MySQL（用户、提交元数据）+ MongoDB（题目、提交答案、AI 评审） |
| **反向代理** | Nginx |
| **容器化** | Docker |
| **版本控制** | Git |

### 3.2 核心技术能力

1. **"黑盒+白盒"双维度智能判卷**：结合大模型实现代码正确性（黑盒测试）与代码质量（白盒分析）的双维度评价
2. **多模态反作弊体系**：融合切屏检测、全屏锁定、代码查重、行为分析等多种防作弊手段
3. **Docker 容器化沙箱**：保障代码运行安全隔离，支持多语言（C/Python/Java 等）在线编译运行
4. **AI 辅助评阅**：大模型辅助代码评阅，提供个性化反馈与优化建议
5. **学情数据分析**：全过程学习数据采集与分析，实现能力画像与教学诊断

## 四、核心功能模块

### 4.1 功能全景

| 功能模块 | 说明 |
|----------|------|
| **在线编程环境** | 支持多语言在线编辑、编译与运行 |
| **智能判卷** | AI 双维度（黑盒+白盒）自动评阅 |
| **反作弊系统** | 切屏检测、全屏锁定、代码查重、行为监测 |
| **学情分析** | 学习数据采集、能力画像、成绩统计与分析 |
| **课程题库管理** | 课程专属题库搭建、题目管理与自动出题 |
| **考试管理** | 支持平时作业、随堂测验、实验考核、期末机考全流程 |
| **多角色界面** | 学生端、教师端、管理员端三类专属交互界面 |
| **平台运营管理** | 用户管理、CSV 导入、系统配置、限流阈值、操作审计与数据库监控 |

### 4.2 判卷流程

- 判卷响应时间：≤3秒/人
- 支持语言：C、Python、Java 等主流编程语言
- 判卷方式：黑盒测试（功能正确性）+ 白盒分析（代码质量、风格、复杂度）

### 4.3 反作弊体系

- 浏览器端权限管控与行为监测
- 切屏检测与全屏锁定
- 代码查重（借鉴 MOSS 平台技术思路）
- 本地优先、弱网兼容设计，确保断网/限网环境下核心功能可用

## 五、开发计划

### 5.1 开发周期：11个月（2026年5月 - 2027年4月）

#### 第一阶段：原型验证（5个月）

- 完成在线代码编辑器与编译运行内核的联调
- 实现基于开源 LLM 的编程题智能判卷基础功能
- 支持 C/Python/Java 等语言
- 在机房单台服务器上完成 50 人并发测试
- 验证判卷响应时间 ≤3秒/人

#### 第二阶段：功能完善（6个月）

- 增加防作弊模块
- 开发题库爬虫工具，增加时间复杂度自动统计
- 开发教师管理端
- 撰写技术文档并申请软件著作权

### 5.2 开发模式

全程采用**敏捷开发模式**，实行周例会、双周迭代制度，明确阶段目标、任务分工与验收标准，使用 Git 进行代码协同与版本控制。

## 六、部署方案

### 6.1 部署方式

- **本地化部署**：支持高校本地服务器部署，提供低成本、易维护方案
- **云端部署**：支持阿里云等云平台部署（可使用学生优惠套餐）
- **轻量化设计**：简化部署流程，无需高校配备专业运维团队
- **统一入口**：使用 Nginx 提供前端静态资源和 `/api` 反向代理，学生、教师、管理端共用一套构建产物

### 6.2 硬件需求

- 借用学校机房服务器
- 或使用阿里云学生优惠套餐

### 6.3 软件资源

全部软硬件在校内现有资源或免费/低成本方案内解决，响应《"人工智能+教育"行动计划》"低成本、广覆盖"原则。

7. **可扩展性强**：模块化架构支持未来扩展 AI 自动出题、代码纠错指导、跨校联合考试、就业能力测评等功能

## 八、教学闭环

平台形成 **"教学 → 考核 → 学情分析 → 反馈改进"** 的完整闭环：

1. **教学**：教师通过平台布置作业、组织测验
2. **考核**：学生在线完成编程任务，系统自动评判
3. **学情分析**：系统采集全过程数据，生成能力画像与学情报告
4. **反馈改进**：教师根据学情数据调整教学策略，实现因材施教

推动教学评价从"结果打分"向"过程育人"转型。
