# 2026-08-23 开发记录

> 日期：2026-08-23
> 记录范围：学生端答题页改分页（一题一页）+ 修复返回按钮卡死

## 一、需求背景

08-21 上线的 `ExamSolve.vue` 把整卷所有题目铺在一个长页面上，每题一个 Monaco 编辑器。在实际使用中暴露两个问题：

1. **返回按钮卡死**：页面上同时存在 N 个 Monaco 编辑器实例，离开页面时一次性 `dispose` 容易卡住主线程
2. **作答体验差**：题目多时整页滚动，定位单题、跳题都不方便

本次改为「一道题一页」的分页模式，单编辑器实例。

## 二、前端改动（ExamSolve.vue）

### 1. 单编辑器分页

- 移除「每题一个 Monaco 编辑器同时存在」的写法，改为**单个编辑器 + `current` 下标**
- `currentQuestion` 计算属性指向当前题目；切换题目时 `goQuestion(i)` → `nextTick(() => initEditor())` 重新装载
- `initEditor()` 切换时先 `disposeEditor()` 再创建，保证同一时刻只有一个编辑器实例
- `disposeEditor()` 加 `try/catch` 兜底，避免 dispose 抛异常把整个页面卡住

### 2. 题号跳转条 + 上下翻页

- 顶部新增 `.qstrip` 题号条：`1 2 3 4 ...`，当前题蓝底白字，已作答绿框
- `isAnswered(i)`：判断是否真正作答（有内容且不是默认模板）
- 底部新增 `.footer`：`上一题` / `第 X / N 题` / `下一题` / `交卷`
- `page-indicator` 显示当前进度

### 3. 草稿与作答判定

- 草稿 key 仍按 `codejudge_draft_{examId}_{questionId}` 存储，切题时不丢
- `normalizeAnswer(q, code)`：交卷时把「空白」和「还是默认模板」的题目都归一为 `''`，后端记为 `UNANSWERED` 0 分
- `defaultTemplate(methodName)` 提到方法级常量，`isAnswered` 与 `normalizeAnswer` 共用，避免判定不一致

### 4. 返回按钮修复

- `goBack()` 显式 `disposeEditor()` + `clearInterval(timer)` 再 `router.push('/student/home')`
- `onBeforeUnmount` 同样清理，作为路由级兜底

## 三、验证结果

- `npm run build` 通过
- 前端 5173 / 后端 8080 端到端联调：
  - 进入试卷 → 默认显示第 1 题，编辑器正常加载
  - 点击题号条 2 → 切到第 2 题，编辑器重新装载、草稿恢复
  - 返回按钮 → 立即响应，不再卡死
  - 倒计时到 0 → 触发自动交卷，已作答/未作答数与预期一致
  - 未写任何代码的题目 → 后端落库 `UNANSWERED`，前端显示「未作答」
