### 3. TeacherQuestion 补齐 methodSignature

**问题**：`TeacherQuestion` 实体没有 `methodSignature` 字段，导致教师端创建/编辑题目时方法签名丢失，容器判题无法生成 Main 包装类。

**修复**（4 个文件）：
- `TeacherQuestion.java`：新增 `methodSignature` 字段 + getter/setter
- `QuestionRequest.java`：record 新增 `methodSignature` 参数
- `TeacherQuestionDetail.java`：新增 `methodSignature` 字段 + `from()` 工厂方法
- `TeacherQuestionService.java`：`apply()` 加 `question.setMethodSignature(request.methodSignature())`

**根因**：`TeacherQuestion` 和 `Question` 共享 MongoDB `questions` 集合，但 `TeacherQuestion` 实体缺少 `methodSignature` 字段，导致教师端写入时签名丢失。

### 5. qlTreeNode 树序列化 bug 修复

**问题**：`qlTreeNode` 方法用 `ArrayDeque` 做 BFS 队列，但 `ArrayDeque.add(null)` 抛 `NullPointerException`。当树有 null 子节点时序列化崩溃。

**修复**：`ArrayDeque` → `LinkedList`（允许 null 元素）

**影响**：之前所有树类题目（层序遍历、合并二叉树等）的输出序列化都会 NPE，现在修复后正常输出 `[3,4,5,5,4,null,7]`。
