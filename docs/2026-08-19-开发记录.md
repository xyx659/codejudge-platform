## 一、今天已完成

### 1. 每题只允许提交一次，提交后可回看题目和自己的回答

- `SubmissionRepository` 新增 `findFirstByStudentIdAndQuestionId`、`findByStudentIdAndQuestionIdIn`
- `StudentService.submit`：提交前校验该题是否已提交过，已提交则拒绝（`该题目已提交过，不能重复提交`）
- `QuestionSummary` 增加 `submitted` 字段，学生列表据此显示「已提交」徽章
- 新增 `StudentQuestionSubmission` DTO + 接口 `GET /student/questions/{id}/submission`，返回当前学生对某题的提交（源码 + 评测结果 + AI 评审；未提交返回 null）
- `QuestionSolve.vue`：已提交时编辑器切换为「我的答案（只读）」，隐藏提交/自测按钮；提交成功后自动刷新进入只读回看
- 联调验证：重复提交返回 400；提交后可查回源码、得分 91、测试结果与 AI 评审

### 2. 学生端只能看见教师端发布的题目（用 Redis 做可见性索引）

- 新增 `spring-boot-starter-data-redis` 依赖 + `application.yml` 的 Redis 连接配置（`REDIS_HOST`/`REDIS_PORT` 可环境覆盖）
- 新增 `QuestionVisibilityIndex` 组件：用 Redis Set `codejudge:visible:question:ids` 维护「教师端发布的题目」ID 并集 = **单题发布（published=true）∪ 已发布试卷（exams.status=PUBLISHED）里的题目**
  - `rebuild()`：发布/关闭/删除/修改试卷、以及单题发布/下架/改/删后重算并写回 Redis
  - `getVisibleIds()`：优先读 Redis，索引为空或 Redis 不可用时回退 MongoDB 计算并尽量回写（容错）
- `ExamService`：publish / close / delete / update 四个入口在 MongoDB 写后调用 `visibilityIndex.rebuild()`
- `TeacherQuestionService`：create / update / delete / publish 四个入口在 MongoDB 写后调用 `visibilityIndex.rebuild()`
- `QuestionRepository` 新增 `findByPublishedTrue()` 查所有单题已发布题目
- `StudentService`：listQuestions / getQuestion / submit 三处可见性判断从原来的 `published=true` 改为按可见索引过滤

> **修复**：初版只统计了「已发布试卷里的题目」，导致教师端「发布题目」按钮（单题 `published=true`）后学生端不同步。已改为并集，并补上 `TeacherQuestionService` 的索引重建。已验证：下架题目「1」→ 学生列表变 1 道；重新发布 → 回到 2 道，实时同步。
- 环境搭建：本机无 redis-server、无 docker、无免密 sudo → 从源码编译安装用户级 Redis 7.2.5 到 `/home/xiao/.local/redis`（`make MALLOC=libc`），`redis-server --daemonize yes` 启动于 127.0.0.1:6379
- 联调验证：教师新建并发布试卷后，学生列表 `total` 从 0 → 1（出现「两数之和」）；Redis `SMEMBERS codejudge:visible:question:ids` 命中该题 ID；二次请求无「回退 MongoDB」告警，确认走 Redis 快路径

### 3. 学生端 Java 代码编辑器 + 自动导包（移除自测）

- 编辑器语言从 JavaScript 改为 Java（`monaco.js` 里 `language: 'java'`，移除 TS worker，仅保留基础 editor.worker）

## 三、启动 Redis 的常用命令（备忘）

```bash
# 启动（幂等，重复执行会提示已在运行）
/home/xiao/.local/redis/redis-7.2.5/src/redis-server --daemonize yes \
  --port 6379 --dir /home/xiao/.local/redis --bind 127.0.0.1 --save "" --appendonly no

# 检查
/home/xiao/.local/redis/redis-7.2.5/src/redis-cli -p 6379 ping          # PONG
/home/xiao/.local/redis/redis-7.2.5/src/redis-cli -p 6379 SMEMBERS codejudge:visible:question:ids
```
