### 2. Monaco 代码编辑器与「像 IDEA」的自动补全

- 新增 `frontend/src/utils/monaco.js`：加载 `editor.worker` + `ts.worker`（TypeScript 语言服务为 JavaScript 提供单词/函数/签名补全）
- 配置 `wordBasedSuggestions: 'currentDocument'`、`tabCompletion: 'on'`、`suggestOnTriggerCharacters`、`parameterHints` 等，接近 IDE 补全体验
- `vite.config.js` 增加 `optimizeDeps.exclude: ['monaco-editor']`，避免 worker 预打包导致实例不一致

### 3. 本地样例自测（浏览器内跑，不占后端）

- 新增 `frontend/src/utils/jsRunner.js`：Blob 内联 Web Worker 隔离执行学生 JS 代码 + 3 秒超时终止
- 输入按空格分隔标量解析成实参，输出转字符串与期望比对，返回每例通过/失败与耗时

### 4. 学生端联调 Bug 修复

- 「开始答题」报 `Cannot read properties of null (reading 'parentNode')`：编辑器挂载时序问题，改为 loading 结束 → `nextTick` → 再创建 Monaco
- 点击「样例自测」无响应：`runLocalTests` 补 try/catch + Worker 创建失败兜底
- `Failed to execute 'postMessage' on 'Worker': [object Array] could not be cloned`：Vue reactive Proxy 无法结构化克隆，发送前对 testCases 做深拷贝
- 编辑器只有高亮、无补全（`Could not find source file: 'inmemory://model/1'`）：移除 `setCompilerOptions()` / `setDiagnosticsOptions()`（monaco-editor issue #4364）
