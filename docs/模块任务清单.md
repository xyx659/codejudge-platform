## 一、项目现状

**技术栈**：Vue 3 + Vite + Vue Router（前端）｜ Java 17 + Spring Boot 3（后端）｜ MySQL（用户、提交元数据）+ MongoDB（题目、提交明细）｜ Judge0 CE + Docker 沙箱（评测）｜ 大模型 API（AI 评审）

**已完成（基础骨架）**

- [x] 前后端分离项目骨架，可编译、可运行
- [x] MySQL + MongoDB 混合存储 + Docker Compose 一键启动
- [x] 实体层（6 个实体）+ 仓储层（4 个 Repository）
- [x] 控制器层（学生/教师/管理端 + 数据库检查，**均为占位实现**）
- [x] `schema.sql` 显式建表（`ddl-auto: none`，表结构由脚本管控）
- [x] BCrypt 密码加密存储
- [x] 统一返回 `ApiResponse` + 全局异常处理
- [x] 种子数据（3 角色账号 + 示例题目 + 示例提交）
- [x] 前端三角色路由 + 布局 + 占位页面
- [x] 前端 API 封装（get/post + 业务码校验）
- [x] 全库代码中文注释

**关键缺口**

- [ ] 登录鉴权与 RBAC（Spring Security 尚未接入）
- [ ] service / DTO 分层（目前 controller 直接返回 Map）
- [ ] 全部业务功能（题库 / 提交 / 判卷 / AI 评审 / 反作弊 / 学情）

## 四、推荐开发顺序（关键路径）

1. **M1 认证** —— 阻塞所有业务，最先做
2. **M0 收尾** —— Flyway / 多环境配置（可与 M1 并行）
3. **M2/M3/M4 基础 CRUD** —— 跑通 controller → service → repository 全链路（顺带补齐 service/DTO 分层）
4. **M5 评测链路** —— 核心价值，判题跑通
5. **M6 AI 评审** —— 依赖 M5
6. **M7 反作弊** —— 依赖考试场景（M3）
7. **M8 学情分析** —— 依赖提交与成绩数据
8. **M10 部署** —— 贯穿全程，最后整合
